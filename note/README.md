## 貼り付け方

1. 記事ファイルを開いて、**`---` より下の本文**をコピー（上のメモ部分は貼らないでください）
2. noteの編集画面に貼り付ける
3. `## ` で始まる行を、noteの **「大見出し」** に設定する
4. `〈画像：6-1.jpg〉` と書いてある場所に、`images/` フォルダの同じ名前の画像を差し込む
5. 〈画像：〉の行自体は削除する
6. `> ` で始まる行は、noteの **「引用」** にすると読みやすくなります

## 書き方の方針

- **noteは検索から読まれるストック型**なので、日付や「今日は」といった時事的な表現は入れていません。半年後に読んでも成立します
- 9本それぞれが**単体で読める**ようにしてあります（順番に読まなくてもわかる）
- 断定的な利回りの話や「増えます」といった表現は入れていません
- 各記事の最後に、SNSへの導線を1行入れてあります
